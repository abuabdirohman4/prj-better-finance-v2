### Task 3 — Handle extra header row

**File:** `scripts/migrate-sheet.ts`

Di fungsi yang deteksi header (cari `normalizeHeader` caller + row header index). Kalau 2025 punya baris AKTIVA/PASIVA di `rows[0]` dan header asli di `rows[1]`:

```ts
// Deteksi: kalau baris pertama mengandung "AKTIVA" / "PASIVA" → header sesungguhnya di baris berikutnya
function findHeaderRow(rows: string[][]): number {
  for (let i = 0; i < Math.min(3, rows.length); i++) {
    const joined = rows[i].join(" ").toUpperCase();
    if (joined.includes("AKTIVA") || joined.includes("PASIVA")) continue; // skip baris label section
    if (rows[i].some(c => /date|category|wallet|atm/i.test(c))) return i;   // baris header data
  }
  return 0;
}
```

Terapkan offset ini di parsing per-tab untuk tahun 2025. 2026 tetap header di baris 0 (fungsi return 0 kalau tak ada AKTIVA/PASIVA).
