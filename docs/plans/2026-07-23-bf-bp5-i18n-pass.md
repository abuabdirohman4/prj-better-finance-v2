# Plan: Global i18n Pass (bf-bp5)

**Date:** 2026-07-23
**Issue:** bf-bp5 · P2 Task
**Scope:** Konsolidasi wording jadi English-first + siapkan layer i18n untuk multi-bahasa (Indonesian menyusul)

---

## Context

Sesi bf-ez2 nge-translate wishlist ke English, tapi menyisakan **shared strings** yang dipakai lintas fitur — nggak boleh di-translate per-fitur karena akan ripple. Rule "English-first" sudah ada di `AGENTS.md` § "Language: English-first".

**Debt konkret yang ketemu:**
1. `ErrorContext` union di `src/lib/errorUtils.ts` — 9 member masih Indonesian (`"memuat data"`, `"menyimpan data"`, dll). Dipakai sebagai arg `handleApiError(err, "...")` di SEMUA `actions.ts`.
2. `getErrorMessage` fallback: `"Terjadi kesalahan yang tidak diketahui"`.
3. Sisa Indonesian UI strings di fitur yang belum di-EN-kan (transactions, budgets, goals, assets, settings, accounts) — wishlist sudah English.

**Keputusan arsitektur yang HARUS diambil dulu (Explore phase):**
- **Opsi A — Hardcode English** (ganti semua string jadi English literal, tanpa lib). Simpel, cepat, tapi Indonesian nanti butuh refactor lagi.
- **Opsi B — Pasang i18n lib** (`next-intl` — cocok App Router). Semua string jadi key → `t("error.load")`, file locale `en.json`/`id.json`. Lebih kerja di depan, tapi multi-bahasa tinggal tambah `id.json`.

> **Rekomendasi:** Opsi B kalau multi-bahasa memang pasti dikerjakan (user sudah bilang "nanti ada fitur multi bahasa"). Opsi A kalau mau cepat & multi-bahasa masih jauh. **Ambil keputusan ini di Explore, jangan asal.**
